# Rubric: is this a good first issue?

## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
|  |  |  |  |


| Maintainer activity | Repo-facts block: maintainer activity and issue comment thread | Pass if a maintainer has responded to an issue or pull request within the last 30 days. | required |
| Repository activity | Repo-facts block: last 5 default-branch commit dates | Pass if at least one commit was made within the last 90 days. | required |
| Manageable scope | Issue body, reproduction steps, and comment thread | Pass if the issue describes one identifiable problem or improvement, provides enough information to identify the affected behavior, and does not require a major architectural redesign. | required |
| Existing ownership | Repo-facts block: assignees and issue comment thread | Pass if the issue has no assignee and no contributor has explicitly stated that they are currently implementing a fix. | required |

## Verdict rule

Accept an issue only when all four required checks pass. Reject it if any required check fails or is unclear. Evaluate each check using the available evidence rather than assumptions. Preferred checks, if added later, may help rank accepted issues but cannot change the accept or reject verdict.
